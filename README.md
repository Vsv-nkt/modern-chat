# Modern Chat

Мобільний месенджер на React Native (Expo) з real-time синхронізацією через Convex.

## 🎯 Функції

- **Авторизація** — реєстрація та вхід через Email + Password (Convex Auth).
- **Чат-кімнати** — створення, список, видалення автором.
- **Real-time чат** — миттєве надсилання та отримання повідомлень.
- **Профіль** — перегляд даних та вихід з акаунту.
- **Темна тема** — сучасний темний інтерфейс на NativeWind (Tailwind).

## 🛠 Технології

- React Native + Expo (SDK 57)
- Expo Router (файловий роутинг)
- **Convex** — backend + real-time
- **Convex Auth** — авторизація
- **NativeWind v4** — Tailwind CSS для RN
- TypeScript
