## 🆕 ДЗ 8: Просунутий функціонал

### ✏️ Редагування повідомлень

- Довге натискання на власне повідомлення відкриває меню дій.
- Відредаговане повідомлення отримує позначку `(ред.)`.
- Режим редагування можна скасувати хрестиком.

### 🗑️ Видалення повідомлень

- Видаляються лише власні повідомлення.
- При видаленні останнього повідомлення в кімнаті оновлюється preview у списку.
- Медіафайли видаляються з Convex Storage.

### 📷 Відправка фото

- Вибір з галереї через `expo-image-picker`.
- Завантаження у Convex Storage через blob.
- Прев'ю перед відправкою з можливістю скасування.
- Повноекранний перегляд у `ImageViewerModal`.

### ⌨️ Індикатор набору тексту

- Таблиця `typingIndicators` у Convex.
- Тротлінг 1.5 секунди (не більше одного запиту).
- Анімовані три точки над полем вводу.
- Зникає автоматично через 3 секунди.
