## 🆕 ДЗ 9 + Додатково: Свайпи та профілі

### 👥 Свайп-керування кімнатами

- Свайп карточки кімнати вліво → червона панель «Видалити».
- Видаляти може лише творець кімнати.
- Видаляються всі повідомлення, файли з Storage та typing-indicators.

### 💬 Відповіді на повідомлення

- Свайп вправо на повідомленні → панель `ReplyPreviewBar`.
- Блок цитати всередині повідомлення.

### 👤 Профілі

- Свій профіль: аватар, ім'я, нік, bio, статистика.
- Редагування через `EditProfileModal`.
- Публічний профіль співрозмовника.
