## 🆕 ДЗ 9: Жести, цитування та профілі

### 💬 Відповіді на повідомлення

- Свайп вправо або довге натискання → «Відповісти».
- Панель `ReplyPreviewBar` над полем вводу.
- Блок цитати всередині повідомлення з кольоровою полоскою.

### 👤 Екосистема профілів

- Свій профіль: аватар, ім'я, `@username`, email, bio.
- Статистика: повідомлення, створені кімнати.
- Редагування через `EditProfileModal` — зміна аватара (Convex Storage), імені, ніка, bio.
- Публічний профіль співрозмовника (`app/user/[id].tsx`).
