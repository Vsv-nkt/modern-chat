## 🆕 ДЗ 11: Голосові повідомлення та реакції

### 🎙️ Голосові повідомлення (expo-audio)

- Запис через мікрофон (кнопка 🎤).
- Панель запису з червоним індикатором і таймером.
- Завантаження `.m4a` у Convex Storage.
- Плеєр `VoiceMessagePlayer` — play/pause, прогрес-бар, час.

### 🔥 Реакції емодзі

- Двойний тап або довге натискання → «Реакція».
- Панель емодзі: 👍 ❤️ 🔥 😂 😮 😢.
- Бейджі `ReactionBadges` під повідомленням.
- Підсвічування «своєї» реакції.
- Real-time синхронізація.
